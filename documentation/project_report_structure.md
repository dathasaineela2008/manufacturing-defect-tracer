# Final project report structure

Suggested chapter outline for the college report (write in your own words).

1. **Title page** — MDTPS, student name, register number, department, year
2. **Certificate / declaration** — college format
3. **Abstract** — problem, traceability approach, academic modules, fictional data disclaimer
4. **Contents, list of figures, list of tables**
5. **Chapter 1 Introduction** — problem statement, objectives, scope, limitations
6. **Chapter 2 Literature / background** — ER model, relational algebra, B-Tree, classification (textbook concepts only; do not invent papers)
7. **Chapter 3 System analysis** — existing difficulty of tracing defects, proposed system, feasibility
8. **Chapter 4 System design** — architecture, ER diagram, schema, DFD or use-case if required by your template
9. **Chapter 5 Implementation** — Flask modules, OOP classes, B-Tree, classifier, UI pages
10. **Chapter 6 Subject mapping** — copy and explain the mapping table
11. **Chapter 7 Testing** — use `documentation/testing.md`
12. **Chapter 8 Results and discussion** — screenshots of U10025 trace; state association vs causation
13. **Chapter 9 Conclusion and future work**
14. **References** — class textbooks (DBMS, DMGT, ADSA, OOP, Python) only
15. **Appendix** — schema.sql excerpt, sample login, installation (PowerShell)

**Disclaimer paragraph to include:**  
All manufacturing records are fictional. The classifier is trained on generated sample data. Tracing answers which product, batch, and machine are stored for a unit. It does not prove that a machine caused a defect.
